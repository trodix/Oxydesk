Where to configure

1. Command line

Highest priority. rdsktp --fps 60 --listen 127.0.0.1:3389. To make the service use options, add a drop-in with systemctl edit rdsktp that overrides ExecStart=.

2. Drop-ins

/etc/rdsktp/rdsktp.conf.d/*.conf, read in alphabetical order, key by key over the main file. Put your local changes here, e.g. 10-local.conf.

3. Main file

/etc/rdsktp/rdsktp.conf, fully commented, key = value lines. The keys are the long options without --. Kept on package upgrades.

4. Defaults

Built in. Shown under each setting below. An unknown key stops the server at start-up, so a typo is never silently ignored.

Apply changes with systemctl restart rdsktp. Use another file with rdsktp --config FILE (its drop-ins are then FILE.d/*.conf). Lines starting with # or ; are comments; there are no trailing comments, and a value may be wrapped in double quotes.

# /etc/rdsktp/rdsktp.conf.d/10-local.conf
listen = 0.0.0.0:3389
fps = 60
max-login-failures = 3
printer-mode = xps,HP*=raw:pcl
